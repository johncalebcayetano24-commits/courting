# Romantic Piano Audio Asset

This directory holds `romantic-piano.mp3`, an original 72 BPM instrumental felt-piano composition created specifically for **A Little Question for Zey**.

## Replacing the Audio Track (Optional)

If you would prefer to use a different original or properly licensed royalty-free acoustic piano recording:

1. Obtain an MP3 track (recommended: 65–80 BPM soft solo piano, no vocals, ~1–3 MB for fast mobile loading).
2. Rename your file to `romantic-piano.mp3`.
3. Replace `assets/music/romantic-piano.mp3` with your file.
4. Keep the filename unchanged so `index.html` and `assets/js/main.js` load it automatically.
